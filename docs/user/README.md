# sky-la user guide

sky-la keeps the books of a Czech OSVČ or a micro-company on your own computer, encrypted. It issues invoices, reads your bank statements, prepares the DPH return and the kontrolní hlášení, and works out your income tax and insurance scenarios. Its advisors run through your own Claude Code and only ever **propose**: nothing reaches your books unless you approve it.

> **Not tax advice.** sky-la's rule pack (the rates, thresholds and deadlines it calculates with) is a draft until it has been reviewed line by line. Every figure that depends on it says so. Treat what sky-la prepares as a draft for your review, and check it before you file or pay.
