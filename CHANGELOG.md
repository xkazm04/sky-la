# Changelog

Each release's first paragraph is what the app's opt-in update check shows. Versions follow [semantic versioning](https://semver.org); before 1.0, a minor version may change the file format, with a migration.

## 0.1.0

The first preview: encrypted, local-first double-entry books for a Czech OSVČ, with invoices (PDF with QR Platba, ISDOC, UBL and CII), bank statements with explained matches, the DPH return and kontrolní hlášení, the income-tax and insurance scenarios, an obligations calendar, backups with a restore drill, import from Pohoda and Fakturoid, and a full export. Advisors run through your own Claude Code and only propose. The rule pack is a draft: check every figure before you file.
